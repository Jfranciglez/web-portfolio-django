# 🌐 Portafolio Personal — Jennifer Franci González Carrillo

Este es mi portafolio web, diseñado para reflejar mi estilo limpio, moderno y minimalista.  
El proyecto presenta mi perfil como **desarrolladora web full stack en formación**, mostrando mis proyectos, habilidades técnicas y formas de contacto.

---

## 🚀 Tecnologías utilizadas
- **Backend:** Django (Python)
- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Iconos y recursos:** Devicon, Font Awesome
- **Plantillas dinámicas:** Django Template Language (DTL)
- **Despliegue local y adaptable a producción**

---

## 💡 Características
- Sección de presentación con foto y descripción profesional.  
- Apartado de proyectos cargado dinámicamente desde un diccionario.  
- Listado de habilidades con iconos visuales y nivel de dominio. 
- Animaciones suaves y diseño responsive.  
- Sección de contacto con enlaces a redes profesionales.
